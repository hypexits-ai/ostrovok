# Островок

Островок для Windows 10/11 в духе Dynamic Island: живёт вверху экрана, показывает главное и раскрывается при наведении. Из него можно запускать программы, переключать окна, управлять музыкой, звуком и Bluetooth, а ещё в нём видны уведомления Telegram.

## Что умеет

**В свёрнутом виде:** иконки открытых программ, время, эквалайзер, который двигается в такт музыке, загрузка или температура процессора, значок с числом непрочитанных в Telegram.
Если на островок 5 минут не наводить мышь, он сжимается до самого маленького вида: время, музыка, процессор и видеокарта.
Во время записи экрана перед значками процессора и видеокарты мигает красная точка, а пока вы делаете снимок «Ножницами» (Win+Shift+S), там появляется фотоаппарат. Пока вверху экрана панель «Ножниц», островок опускается под неё, чтобы не закрывать кнопки.

**В раскрытом виде** (наведите мышь или подведите её к самому верхнему краю экрана). В игре и поверх любого полноэкранного окна островок раскрывается, только если задержать на нём курсор, а при зажатой кнопке мыши не раскрывается совсем. Так он не открывается, когда вы вращаете камеру. Игры островок узнаёт по списку, который ведёт Windows (Xbox Game Bar).
- **Плеер.** Обложка, трек, предыдущий и следующий трек, пауза. Работает со Spotify, Яндекс Музыкой, браузерами и любыми программами, которые сообщают Windows, что играет.
- **Колесо избранного.** Изначально в нём программы, закреплённые на панели задач. Крутится колёсиком мыши (один щелчок — одна программа) или перетаскиванием. Справа от колеса дуга с кружком напротив каждой программы: кружки поворачиваются вместе с колесом и подсвечиваются под курсором. Клик по кружку или по названию сразу запускает программу.
- **Открытые окна.** Клик переключает на окно.
- **Нижняя строка.** Поиск, Wi-Fi, Bluetooth, звук, громкость, загрузка процессора и видеокарты.
- **Яркость экрана.** Ползунок справа: тяните, крутите колёсиком, клик по солнцу или полумесяцу прибавляет или убавляет 10%. На ноутбуке меняется встроенный экран, на компьютере монитор через DDC/CI. Если монитор так не умеет, ползунка нет.
- **Значки сверху.** Как вы подключены к интернету (Wi-Fi с уровнем сигнала, кабель или нет сети) и, на ноутбуке, заряд батареи с процентом внутри. Это просто значки, не кнопки.

**Перетаскивание в урну.** Если схватить окно из списка или плеер, справа отпочкуется красная урна. Брошенное в неё закрывается. Музыка в браузере не закрывает браузер, а только встаёт на паузу.

**Как нажимать:** левый клик выполняет действие (включить Bluetooth, открыть настройки, выключить), правый открывает меню с подробностями.

**Два вида:** капсула под краем экрана или вырез, прижатый к краю. Переключаются стрелками ▲▼ рядом со значком сети.

**Окошки, которые отделяются от островка:**

| Что | Как открыть |
|---|---|
| Поиск приложений, настроек Windows и файлов | клик по строке поиска |
| Календарь, погода, таймер и секундомер | правый клик по времени |
| Большой плеер с перемоткой | правый клик по плееру |
| Редактор избранного | правый клик по колесу |
| Bluetooth-устройства | правый клик по кнопке Bluetooth |
| Сети Wi-Fi | правый клик по кнопке Wi-Fi |
| Устройства вывода, громкость программ, микрофон | правый клик по громкости |
| Что нагружает компьютер | правый клик по кружку процессора или видеокарты (левый открывает Диспетчер задач) |
| Сон, перезагрузка, выключение | правый клик по кнопке питания (левый клик дважды — выключить) |

Окошко закрывается клавишей Esc, кликом мимо или когда мышь уходит с островка.

**Уведомления Telegram.** Аватар, имя и текст сообщения, клик открывает Telegram.

## Установка

1. Скачайте архив `Ostrovok-…-win-x64.zip` из раздела Releases и распакуйте его в любую папку.
2. Запустите **Install.cmd**.
   Windows может предупредить, что программа неизвестна: у неё нет платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».
3. Островок появится вверху экрана и будет запускаться вместе с Windows.

Права администратора не нужны. Программа ставится в `%LOCALAPPDATA%\Programs\Ostrovok`. .NET устанавливать не нужно, он уже внутри.
Нужен Microsoft Edge WebView2 Runtime. В Windows 11 он уже есть, а в Windows 10 установщик сам откроет страницу загрузки, если его не окажется.

**Удаление:** запустите **Uninstall.cmd** из того же архива.
**Настройки:** правый клик по значку островка в трее (рядом с часами). Там автозапуск, показ поверх полноэкранных игр и видео, обновление избранного, папка настроек, перезапуск и выход. Поверх игр в эксклюзивном полноэкранном режиме Windows рисовать не даёт, там островок прячется.

### Уведомления Telegram
Чтобы островок показывал сообщения целиком, Telegram должен отправлять уведомления через Windows:
Telegram → Settings → Notifications and Sounds → System integration → **Use Windows notifications** (в русском интерфейсе: «Использовать уведомления Windows»).
Чтобы сообщение не всплывало дважды, в Windows можно выключить для Telegram баннеры: Параметры → Система → Уведомления → Telegram → снять «Показывать баннеры уведомлений». Галочку «Показывать уведомления в центре уведомлений» оставьте.
Без этой настройки островок показывает только число непрочитанных.

## Какие настройки Windows включить

В архиве лежит файл **«Настройка Windows.txt»**: что включить или выключить, чтобы работало всё (уведомления Telegram, список сетей Wi-Fi, автозапуск, игры на весь экран, снимки экрана и другое). В репозитории он лежит в папке [app/release](app/release/).

## Настройки в файлах

Папка `%LOCALAPPDATA%\Ostrovok`:
- `settings.json`: `City` (город для погоды, его также можно ввести прямо в окошке часов) и `IdleMinutes` (через сколько минут островок сжимается, по умолчанию 5, `0` отключает).
- `favorites.json`: свой список избранного. Его удобнее менять правым кликом по колесу.
- `log.txt`: журнал ошибок.

## Конфиденциальность

Островок ничего не отправляет в интернет, кроме названия вашего города в бесплатный сервис погоды Open-Meteo. Окна, музыку, звук и уведомления он читает только на вашем компьютере.

## Ограничения

- Температура процессора видна, только если Windows её отдаёт (датчики ACPI). Иначе показывается загрузка.
- Wi-Fi: Windows 11 показывает названия сетей только программам с доступом к местоположению, и окошко подскажет, где его включить.
- Bluetooth: подключать и отключать кликом можно только наушники и колонки. Для остальных устройств откроются настройки.
- Запись экрана видна, если программа снимает экран средствами Windows: «Ножницы», показ экрана в Discord и Teams, OBS с захватом Windows. Запись силами видеокарты (например, NVIDIA ShadowPlay) островок может не заметить.
- Яндекс Музыка при смене трека на время загрузки (иногда до 10 секунд) пропадает из Windows. Островок в это время показывает прошлый трек и мягко пульсирует, а нажатую кнопку отправит, как только трек загрузится.
- Переключение устройства вывода и чтение уведомлений Telegram держатся на механизмах Windows, которые официально не описаны. После крупного обновления Windows они могут перестать работать.

## Сборка из исходников

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download).

```
powershell -ExecutionPolicy Bypass -File app\install.ps1    # собрать и установить на этот ПК
powershell -ExecutionPolicy Bypass -File app\pack.ps1       # собрать архив для других: dist\Ostrovok-…-win-x64.zip
```

Устройство: окно на C# (WinForms) с прозрачным WebView2, весь интерфейс написан на HTML/CSS/JS в `app/Ostrovok/ui`. Системные данные (музыка, звук, окна, Bluetooth, Wi-Fi, поиск, процессы, Telegram) собираются в `app/Ostrovok/*.cs`. В `design/` лежат интерактивные макеты, по которым выбирался вид.
