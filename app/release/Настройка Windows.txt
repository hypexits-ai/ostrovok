ОСТРОВОК: КАКИЕ НАСТРОЙКИ ВКЛЮЧИТЬ

Островок работает сразу после установки. Ниже собрано, что стоит включить или
выключить в Windows и других программах, чтобы работало всё. Каждый пункт
можно пропустить, если эта функция вам не нужна.


1. ПЕРВЫЙ ЗАПУСК
----------------
У программы нет платной цифровой подписи, поэтому Windows может показать окно
«Windows защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом
случае». Это нужно сделать один раз.

В Windows 10 нужен Microsoft Edge WebView2 Runtime. Если его нет, установщик сам
откроет страницу загрузки. В Windows 11 он уже есть.


2. ЗАПУСК ВМЕСТЕ С WINDOWS
--------------------------
Установщик включает автозапуск сам. Если островок не появляется после
перезагрузки, проверьте:
  Параметры → Приложения → Автозагрузка → «Островок» (может называться Ostrovok)
  должен быть включён.
То же самое переключается в меню значка островка в трее (рядом с часами):
«Запускать вместе с Windows».

Чтобы значок островка всегда был виден в трее, а не прятался под стрелкой:
  Параметры → Персонализация → Панель задач → Другие значки панели задач →
  включите «Островок».
Через этот значок островок можно перезапустить, если что-то пошло не так.
Ещё его можно запустить из меню Пуск (ярлык Ostrovok).


3. УВЕДОМЛЕНИЯ TELEGRAM
-----------------------
Без настройки островок показывает только число непрочитанных. Чтобы он
показывал сами сообщения (аватар, имя, текст):

  а) В Telegram Desktop:
     Настройки → Уведомления и звуки → включите «Использовать уведомления
     Windows» (в английском интерфейсе: Settings → Notifications and Sounds →
     System integration → Use Windows notifications).

  б) В Windows уведомления должны быть включены:
     Параметры → Система → Уведомления → общий переключатель «Уведомления»
     включён, и в списке приложений Telegram тоже включён.

  в) Чтобы сообщение не всплывало дважды (островком и баннером Windows):
     Параметры → Система → Уведомления → Telegram →
       снимите «Показывать баннеры уведомлений»,
       оставьте «Показывать уведомления в центре уведомлений».
     Галочку центра уведомлений не снимайте: островок берёт сообщения оттуда.

Работает с приложением Telegram Desktop. Веб-версия Telegram в браузере
уведомления островку не передаёт.


4. МУЗЫКА И ПЛЕЕР
-----------------
Островок показывает то, что играет в программах, которые сообщают Windows о
музыке: Spotify, Яндекс Музыка, браузеры, плееры.
Проверить просто: нажмите Win+A. Если трек виден в быстрых настройках Windows
(над ползунком громкости), его увидит и островок. Если там его нет, программа
не сообщает о музыке, и островок его тоже не покажет.


5. WI-FI: СПИСОК СЕТЕЙ
----------------------
Windows 11 показывает названия Wi-Fi-сетей только программам с доступом к
расположению. Чтобы в окошке Wi-Fi был список сетей:
  Параметры → Конфиденциальность и защита → Расположение →
  включите доступ к расположению, в том числе для классических приложений.
В окошке Wi-Fi есть кнопка «Открыть настройки», она открывает этот раздел.
Включение и выключение Wi-Fi работает и без этого.


6. BLUETOOTH
------------
Кнопка Bluetooth включает и выключает Bluetooth.
Подключать и отключать кликом в окошке можно наушники и колонки, которые уже
сопряжены с компьютером. Новое устройство сначала добавьте в Windows:
  Параметры → Bluetooth и устройства → Добавить устройство.


7. ИГРЫ И ВИДЕО НА ВЕСЬ ЭКРАН
-----------------------------
По умолчанию островок остаётся поверх игр и видео на весь экран. Это
переключается в меню значка в трее: «Поверх полноэкранных игр и видео».

В играх выбирайте режим экрана «Оконный без рамки» (Borderless, Windowed
Fullscreen). В эксклюзивном полноэкранном режиме Windows не даёт рисовать
поверх игры, и островок на это время прячется.

В игре островок не раскрывается, когда курсор просто проносится над ним
(например, пока вы вращаете камеру) или когда зажата кнопка мыши. Чтобы
открыть его, задержите на нём курсор примерно на секунду.
Игры островок узнаёт по списку Windows, который ведёт Xbox Game Bar. Если
какую-то игру он не узнаёт, откройте в ней Game Bar (Win+G) и отметьте
«Запомнить, что это игра» (в настройках Game Bar). Над любым окном на весь
экран (игра или видео) задержка действует и без этого.


8. СНИМКИ И ЗАПИСЬ ЭКРАНА
-------------------------
Фотоаппарат на островке появляется, когда вы делаете снимок «Ножницами»
(Win+Shift+S). Пока вверху экрана панель «Ножниц», островок опускается под неё.

Если вы делаете снимки клавишей Print Screen и хотите, чтобы она тоже открывала
«Ножницы»:
  Параметры → Специальные возможности → Клавиатура → включите пункт про
  кнопку Print Screen и «Ножницы».

Красная точка мигает во время записи или показа экрана: запись в «Ножницах»
(Win+Shift+R), показ экрана в Discord и Teams, OBS с захватом Windows.
Запись силами видеокарты (например, NVIDIA ShadowPlay) островок может не
заметить. Включать для этого ничего не нужно.


9. ПОГОДА
---------
Правый клик по времени → окошко с календарём и погодой → введите свой город.
Погода берётся из бесплатного сервиса Open-Meteo, нужен интернет.


10. ЯРКОСТЬ ЭКРАНА
------------------
Ползунок яркости справа в раскрытом островке.
На ноутбуке он меняет яркость встроенного экрана, настраивать ничего не нужно.
На компьютере островок меняет яркость монитора по DDC/CI. Если ползунка нет,
откройте меню самого монитора (кнопками на мониторе) и включите там пункт
DDC/CI, потом перезапустите островок (меню значка в трее → «Перезапустить»).
Некоторые мониторы DDC/CI не поддерживают, тогда ползунка не будет.
Ползунок меняет яркость основного монитора, на котором живёт островок.


11. НЕСКОЛЬКО МОНИТОРОВ
-----------------------
Островок живёт на основном мониторе. Чтобы перенести его на другой:
  Параметры → Система → Дисплей → выберите монитор →
  «Сделать основным дисплеем».


12. ЧТО НАСТРАИВАТЬ НЕ НУЖНО
----------------------------
- Панель задач островок не меняет.
- Избранное сначала берётся из программ, закреплённых на панели задач.
  Изменить его можно правым кликом по колесу избранного.
- Температура процессора видна, только если Windows получает её от датчиков.
  Если нет, островок показывает загрузку процессора. Включить это нельзя.


Где лежат настройки островка: папка %LOCALAPPDATA%\Ostrovok
(её открывает пункт «Папка настроек» в меню значка в трее).
