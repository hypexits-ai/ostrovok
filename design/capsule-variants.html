Островок: капсула

Форма капсулы, колесо приложений без рамки, компактный плеер без рамки, сверху время, дата, параметры и выключение, снизу линия кнопок. Три раскладки отличаются тем, где живёт музыка. Переключите «Музыка → Не запущена», чтобы увидеть, как островок выглядит без неё.

Данные ненастоящие: трек, температура и окна изображены для примера. Кликом по иконке в колесе её можно выбрать, кликом по выбранной — «открыть». Блоки можно переставлять между раскладками: например, взять раскладку А, но добавить в неё список окон из В.
