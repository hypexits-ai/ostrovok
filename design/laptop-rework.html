Островок для ноутбука

Четыре идеи, по нескольку вариантов на каждую. Всё здесь живое: переключайте варианты, нажимайте клавиши и тяните капсулу. Выбирайте вариант кликом по карточке. Внизу страницы соберётся строка с выбором, её можно скопировать и прислать мне.

Свёрнутый вид: время · батарея · раскладка

ЦП и видеокарта убраны полностью. Батарея показывается иконкой без цифр: белая, зелёная с молнией при зарядке, красная при заряде ниже 20%. Раскладка меняется с короткой анимацией. Сверху — обычный свёрнутый остров, снизу — мини-вид после простоя.

Alt+Tab через остров

Остров раскрывается в ленту больших иконок открытых окон, без подписей. Лента прокручивается так же, как колесо избранного, только горизонтально. Каждое нажатие Tab двигает выбор вправо, а лента уезжает справа налево, держа выбранное окно по центру. Как и в Windows, сразу при открытии выбрано предыдущее окно, поэтому одно быстрое Alt+Tab переключает между двумя последними окнами.

Перемещаемая капсула

Только в режиме капсулы. Справа появляются две горизонтальные линии: за них капсулу можно тянуть, а наведение на них не раскрывает остров. Наведите на саму капсулу и подождите — она раскроется, как обычно, и уместится в экран, даже если стоит у нижнего края. Двойной клик по линиям возвращает капсулу на место по центру сверху.

Уведомления вместо окон Windows

Короткие сообщения, которые заменят системные окна Windows. Для смены раскладки есть три варианта, остальные пока в одном. Уведомление Telegram «N непрочитанных» удаляется совсем: остаются только сообщения от конкретных людей.
